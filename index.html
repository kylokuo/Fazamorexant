CBT-I：一致性最高

跨国家、不同方法学体系的推荐方向最稳定；差距更多发生在实施路径，而不是疗效方向。

DORA：更新滞后造成表面差异

AASM 2017 时部分新药证据尚未成熟；欧洲 2023 和 VA/DoD 2025 纳入较新的药物与长期证据，不能把时间差当作药理学冲突。

BZRA / Z 药：短期疗效与长期价值分离

短期入睡或维持改善较明确，但依赖、戒断、跌倒、认知和复杂睡眠行为会拉低长期净获益。

法赞雷生：从“已获批”走向“可长期管理”的循证地图

法赞雷生（Fazamorexant，YZJ-1139）是 OX1R / OX2R 双重 orexin 受体拮抗剂。公开信息显示，国家药监局已批准其用于以入睡困难和 / 或睡眠维持困难为特征的成人失眠患者。现有证据的特点是：早期临床药理和特殊肝功能研究已形成较清晰资产，但长期、真实世界和复杂共病证据尚不足以支撑“低风险、适用于所有人群”的外推。

机制：DORA / OX1R + OX2R 适应证口径：成人失眠 已公开获批：2026-05 证据原则：产品级证据优先，类级证据只作背景
现有强项：临床药理与早期安全 FIH 研究纳入 104 名健康成人；单次 2–80 mg、连续 10–60 mg 7 天，吸收快、半衰期约 1.91–3.68 小时，未观察到严重不良事件或死亡。
最关键的净获益问题：长期安全 目前公开资产不能替代 6–12 个月及更长时间的真实世界安全性，尤其是跌倒、认知、次日功能、停药后反跳、滥用 / 依赖和罕见事件。
最容易被误读的地方：特殊人群 肝功能不全已有单次给药 PK 信号，但肾功能不全、老年失眠患者、焦虑 / 抑郁共病和多药联用不能用健康志愿者或 DORA 类证据直接替代。

证据成熟度怎么读

已有产品资产 ：存在产品级临床 / 监管资料，但仍有外推边界
已有部分证据 ：方向已有信号，样本、疗程或人群不足
关键缺口 ：公开来源未形成可用于决策的直接产品级证据

证据使用边界

Phase I 只能回答临床药理和短期耐受，不能回答失眠患者的长期疗效和真实世界安全。

DORA 类级证据可帮助建立科学背景，但不能替代法赞雷生的剂量、相互作用、共病和标签证据。

“未检出公开证据”不是“证明无风险”；路线图优先补齐能改变处方决策的缺口。

建议的决策顺序

  1. 先完成长期安全与风险管理底座。
  2. 再补老年、肝肾和多药联用的剂量 / 安全边界。
  3. 最后用共病人群和真实世界比较证据支撑差异化与指南沟通。

三年循证规划路线图

以 2026 年获批后的首个完整三年周期为例。每年同时推进“安全底座、特殊人群、临床价值传播”三条线；具体样本量、研究设计和时间表需结合药物警戒信号、监管要求与预算再冻结。

YEAR 1 · 2027

建立安全与剂量边界

  • 完成上市后安全性登记 / RWD 基线，统一 TEAE、严重事件、跌倒、认知、次日功能、停药 / 反跳和依赖相关定义。
  • 开展肾功能不全 PK / 安全研究，覆盖 eGFR 分层；同步评估透析场景是否需要独立研究。
  • 扩展老年真实失眠患者研究，纳入多病共存、多药联用、跌倒风险和认知测量。
  • 形成 CYP3A 抑制剂 / 诱导剂、抗抑郁药、抗焦虑药、阿片 / 其他中枢抑制剂的相互作用优先矩阵。
年度交付： 证据基线白皮书、风险管理问题清单、肾功能 / 老年研究方案、首批上市后安全信号报告。
YEAR 2 · 2028

验证长期获益与共病价值

  • 推进 6–12 个月及更长期安全性 / 有效性随访，观察持续使用、停药后睡眠、次日功能和罕见不良事件。
  • 开展焦虑 / 抑郁共病研究，至少同步测量 ISI、睡眠日记、PHQ-9、GAD-7、日间功能与合并用药。
  • 补充 Child-Pugh A / B 多次给药及 Child-Pugh C / 慢性肝病边界的监管沟通与研究证据。
  • 建立与 BZRA / Z 药、其他 DORA 或 CBT-I 的真实世界比较队列，优先关注老年和多药联用患者。
年度交付： 长期安全中期报告、共病人群研究结果、老年 / 肝肾专题论文或会议摘要、处方决策工具包。
YEAR 3 · 2029

整合证据并进入指南语境

  • 完成累积获益—风险评估，按年龄、肝肾功能、精神共病、合并用药和跌倒 / 认知风险分层。
  • 把真实世界结果转化为临床路径、共识 / 指南提案和医学沟通材料；明确哪些主张有产品级证据、哪些仍只能用 DORA 类证据支持。
  • 围绕“可长期管理、次日功能、特殊人群可用性”形成比较性证据包，支持上市后标签 / 风险管理更新评估。
  • 完成 3 年研究资产归档、数据标准化和后续 5 年更新机制，避免证据只停留在单篇论文。
年度交付： 综合证据地图 2.0、长期安全最终报告、指南介入包、下一周期研究优先级和预算建议。

  2. 特殊人群：老年、肝肾功能、OSA、多病共存。
  3. 共病价值：焦虑 / 抑郁、抗抑郁药联用和 CBT-I 互补。

使用边界

公开作者数据库可支持学术相关性初筛，不能替代当前任职、近期课题、利益冲突和真实合作意愿核验。

“高相关”不等于“会支持产品”；首轮接触应优先讨论未决临床问题和研究设计。

产品相关研究者卡片中的“通讯作者”来自公开论文；通讯作者不必然等同于临床试验 PI，正式合作前需按注册信息 / CSR 复核。
