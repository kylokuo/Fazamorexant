DORA 类

Suvorexant

舒沃雷生 · Belsomra
证据：中入睡维持长期较低信号，但不应宣传为零依赖
药理 / 治疗机制

双重阻断 OX1R / OX2R，降低 orexin 驱动的觉醒张力；不是 GABA-A 增强剂。

主要定位

入睡 + 睡眠维持；AASM 2017 特别针对睡眠维持给出弱推荐。

竞争优势
  • 不直接造成 GABA-A 受体广泛抑制
  • 对睡眠维持有明确定位
  • 长期和老年人已有持续积累的临床数据
局限与副反应
  • 次日嗜睡、头晕、头痛；少数可有睡眠瘫痪、梦魇或异常梦境
  • CYP3A 相互作用、肥胖/睡眠呼吸障碍和跌倒风险需评估
  • “低依赖”不等于没有滥用或长期安全问题
EVIDENCE · 证据边界

证据覆盖指南、剂量—反应及长期 DORA 荟萃分析；优势在睡眠连续性，长期净获益仍受剂量和人群影响。

DORA 类

Lemborexant

莱博雷生 · Dayvigo
证据：中入睡维持次日功能长期较低信号；长期真实世界证据仍在形成
药理 / 治疗机制

高亲和力、可逆性 OX1R / OX2R 拮抗；抑制觉醒系统，保留睡眠—觉醒转换的生理调节。

主要定位

入睡 + 睡眠维持；对老年人和共病人群的差异化潜力是竞争点。

竞争优势
  • 对 WASO、TST、睡眠效率和入睡指标均有信号
  • 老年人、抑郁/焦虑用药亚组有补充数据
  • 不以直接 GABA 增强为机制
局限与副反应
  • 嗜睡、头晕、疲劳；需关注睡眠瘫痪、梦魇等 orexin 相关现象
  • 药物相互作用和次日驾驶/操作风险仍需管理
  • 与安慰剂的长期安全差异可能随时间增加
EVIDENCE · 证据边界

类级荟萃分析支持持续改善，但不同 DORA 的不良事件画像不能互相替代。

DORA 类

Daridorexant

达利雷生 · Quviviq
证据：中入睡维持次日功能长期较低信号；不替代渐减和监测
药理 / 治疗机制

双重 orexin 受体拮抗；较短的药效学尾部是“次日功能”定位的重要产品叙事。

主要定位

入睡 + 睡眠维持 + 次日功能；可作为长期管理讨论中的新一代选项。

竞争优势
  • 改善入睡、维持和次日功能的证据链较完整
  • 52 周研究和长期荟萃分析支持持续获益
  • 停药/换药领域有研究关注
局限与副反应
  • 仍可出现嗜睡、梦魇、睡眠瘫痪等
  • 长期研究中不同剂量耐受性不完全相同
  • 不能把短期 RCT 的依赖风险结果外推为真实世界“无依赖”
EVIDENCE · 证据边界

在老年人 DORA 综述中安全性信号相对有利；长期证据仍需更长随访与真实世界验证。

苯二氮䓬类

Temazepam / Triazolam

替马西泮 / 三唑仑
证据：高 / 中高入睡维持高：依赖 / 戒断 / 反跳失眠
药理 / 治疗机制

正向变构调节 GABA-A 受体，增强抑制性神经传递；temazepam 偏维持，triazolam 偏入睡。

主要定位

短期、明确症状目标的快速镇静；AASM 对两者均为弱推荐。

竞争优势
  • 起效快、临床经验丰富
  • 入睡或维持的症状靶向较直接
  • 价格和处方端认知通常有优势
局限与副反应
  • 耐受、依赖、戒断和反跳失眠是核心短板
  • 认知减慢、记忆损害、跌倒、呼吸抑制和次日残留
  • 与酒精、阿片或其他中枢抑制剂合用风险显著增加
EVIDENCE · 证据边界

疗效证据并不等于长期价值证据；中长期使用通常需要药物特异性渐减。

苯二氮䓬类

Estazolam

艾司唑仑
证据：中入睡维持高：依赖 / 戒断 / 反跳失眠
药理 / 治疗机制

GABA-A 受体正向变构调节，增强抑制性神经传递；中国处方端常见代表。

主要定位

中国市场中的传统处方竞争品；本卡采用类级证据，不把其他 BZD 的指南推荐移植给 estazolam。

竞争优势
  • 医生和患者认知成熟、起效快
  • 传统处方端可及性较高
  • 对入睡和夜间觉醒均可能有短期帮助
局限与副反应
  • 依赖、戒断、反跳失眠、认知和跌倒风险
  • 老年、多病共存、睡眠呼吸障碍和合并中枢抑制剂时负担更大
  • 长期获益缺少足够高质量证据
EVIDENCE · 证据边界

AASM 2017 逐药推荐的是 temazepam / triazolam；estazolam 在此处以 BZRA 类风险与换药/减停证据呈现。

Z 药

Zolpidem

唑吡坦
证据：高 / 中高入睡维持中—高：依赖与复杂睡眠行为
药理 / 治疗机制

偏向 GABA-A α1 亚基相关位点的正向变构调节；属于 BZRA，但化学结构非 benzodiazepine。

主要定位

入睡为主，也可覆盖维持；AASM 2017 弱推荐。

竞争优势
  • 起效快、短期入睡改善明确
  • 短效制剂便于围绕入睡问题定位
  • 处方端认知成熟
局限与副反应
  • 复杂睡眠行为、遗忘、次日嗜睡、跌倒与驾驶风险
  • 仍存在耐受、依赖、戒断和反跳失眠
  • 女性、老年或肝功能异常等人群需特别关注暴露和次日残留
EVIDENCE · 证据边界

“Z 药”不是无风险版 BZD；换药/减停与 BZRA 同样需要药物特异性管理。

Z 药

Eszopiclone / Zopiclone

右佐匹克隆 / 佐匹克隆
证据：高 / 中高入睡维持中—高：依赖与戒断
药理 / 治疗机制

作用于 GABA-A 受体调节位点，增强抑制性神经传递；eszopiclone 为 AASM 指南代表。

主要定位

入睡 + 维持；适合用于与 DORA、CBT-I 的替代关系讨论。

竞争优势
  • 入睡和维持均有临床定位
  • 较适合夜间维持问题的传统药物比较
  • 长期使用/减停有较多临床经验
局限与副反应
  • 口苦、金属味、嗜睡、认知影响和跌倒
  • 耐受、依赖、戒断、反跳失眠及复杂睡眠行为
  • zopiclone 不应直接套用美国 AASM 对 eszopiclone 的逐药推荐
EVIDENCE · 证据边界

AASM 对 eszopiclone 为弱推荐；zopiclone 作为同类代表展示，需区分国家可及性和说明书。

Z 药

Zaleplon

扎来普隆
证据：高 / 中高入睡中：依赖 / 复杂睡眠行为
药理 / 治疗机制

短效 GABA-A 调节剂；药效学尾部较短，主要针对睡眠启动。

主要定位

入睡困难、夜间临时补救；AASM 2017 弱推荐。

竞争优势
  • 短效，次日残留理论上较少
  • 可将产品定位聚焦于入睡而不是整夜镇静
  • 短期症状目标清晰
局限与副反应
  • 对睡眠维持覆盖有限
  • 仍有遗忘、复杂睡眠行为、依赖和反跳风险
  • 频繁补服会增加暴露与行为风险
EVIDENCE · 证据边界

AASM 逐药支持入睡目标，但短效不等于没有 BZRA 风险。

褪黑素受体激动剂

Ramelteon

雷美尔通 · Rozerem
证据：高 / 中高入睡长期低：不以依赖为主要限制
药理 / 治疗机制

选择性激动 MT1 / MT2，模拟褪黑素对睡眠—觉醒节律和睡眠启动的调节。

主要定位

睡眠启动、昼夜节律倾向和对依赖风险敏感的人群；并非强镇静。

竞争优势
  • 非 GABA 机制，依赖和戒断负担相对低
  • 睡眠启动和节律定位清晰
  • 对老年人和长期管理有一定优势叙事
局限与副反应
  • 效应量通常小于强镇静催眠药，患者主观感知可能不稳定
  • 对严重睡眠维持问题覆盖有限
  • 起效和个体反应受节律、光照和服用时点影响
EVIDENCE · 证据边界

荟萃分析显示 ramelteon 4 周时改善 TST 和入睡潜伏期；AASM 对睡眠启动为弱推荐。

镇静性抗抑郁药

Low-dose Doxepin

低剂量多塞平 · Silenor
证据：高 / 中高维持低—中：无典型 BZRA 依赖，但停药和镇静需管理
药理 / 治疗机制

低剂量主要通过强 H1 受体拮抗增强睡眠维持；高剂量则具有抗抑郁/多受体作用。

主要定位

睡眠维持，尤其是夜间觉醒；AASM 2017 弱推荐。

竞争优势
  • 有明确的睡眠维持定位
  • 低剂量与抗抑郁剂量的机制/负担不能混为一谈
  • 无典型 BZRA 依赖路径
局限与副反应
  • 嗜睡、口干、头晕；高剂量抗胆碱能和心脏风险更突出
  • 对入睡问题不是最强定位
  • 与其他镇静或抗胆碱能药叠加时负担增加
EVIDENCE · 证据边界

AASM 逐药推荐 doxepin 用于睡眠维持；这里的“low-dose”是关键产品边界。

镇静性抗抑郁药

Trazodone

曲唑酮
证据：高 / 中高维持次日功能低—中：停药仍需考虑，但不是 BZRA 型依赖
药理 / 治疗机制

5-HT2A 拮抗 + H1 和 α1 拮抗等多受体作用，镇静并非单一睡眠靶点。

主要定位

临床常见 off-label 竞争品，通常与抑郁、焦虑或疼痛共病场景绑定。

竞争优势
  • 可覆盖抑郁/焦虑共病的临床叙事
  • 不属于 BZRA，依赖模式不同
  • 价格与临床熟悉度常有优势
局限与副反应
  • AASM 对失眠单独使用为不推荐
  • 头晕、镇静、头痛、恶心、体位性低血压；罕见阴茎异常勃起
  • 证据常来自共病或小样本，不能把“困”直接等同于高质量失眠疗效

指南与 2026 抑郁共病荟萃分析共同提示：可有睡眠改善，但净获益和目标人群边界很重要。

镇静性抗抑郁药

Mirtazapine

米氮平
证据：低—中 / 边界清晰维持次日功能长期低—中：抗抑郁药停药管理
药理 / 治疗机制

α2 拮抗增强去甲肾上腺素/5-HT释放，同时拮抗 H1、5-HT2/5-HT3；低剂量常更镇静。

主要定位

抑郁 + 失眠、食欲下降或体重不足等共病场景；不是单纯失眠的一线药。

竞争优势
  • 抑郁共病和睡眠症状可同时处理
  • 对 TST、慢波睡眠和睡眠效率有信号
  • 不以 GABA-A 增强为机制
局限与副反应
  • 体重增加、食欲增加、嗜睡和次日功能影响
  • 低剂量并不自动意味着副作用更少
  • 停药需考虑抗抑郁药撤药症状；证据主要来自抑郁人群
EVIDENCE · 证据边界

2026 系统综述支持抑郁患者的睡眠改善，但不能外推为原发性失眠单药证据。

Zao Ren An Shen 胶囊

枣仁安神胶囊 · ZRAS
证据：低—中 / 边界清晰入睡维持长期药理依赖信号低；质量、一致性和相互作用是主要风险
药理 / 治疗机制

多成分复方；传统定位围绕“养心安神”。现代机制研究涉及 GABA、5-HT、炎症和应激通路，但人体机制尚未标准化。

主要定位

中国市场产品级竞争代表；常见叙事是“非 BZRA、长期负担较轻、可联合”。

竞争优势
  • 有产品级 RCT、系统综述与荟萃分析可追溯
  • 患者对“天然/中成药”接受度可能较高
  • 可作为减轻传统催眠药暴露的替代/联合讨论对象

  • 产品级 RCT 未显示 4 周优于安慰剂；剂量可能影响结果
  • GRADE 从极低到低，长期疗效与一致性不足
  • 复方质量、批间一致性、相互作用和“联合用药”解释复杂

更新节奏怎么读

中国 2017 → 2023版（2024发表）→ 2025版，观察到的重大版本更新约为 6–8 年，但不同学会体系并行，不能简单视为同一文件的年度迭代。

欧洲 2017 → 2023 更新约 6 年；AASM 按药物与行为模块分别更新，没有已核验的统一固定周期。

VA/DoD 以 Version 3.0 体现版本化更新；学会共识多围绕新药、减停药、特定人群或新技术事件驱动。

推荐等级阅读规则

  1. 先看推荐针对的干预、剂量和人群。
  2. 再看推荐强度与证据质量是否同向。
  3. 最后看文件类型：总纲指南、立场背书和特定药物共识不能等量齐观。

当前最重要的证据缺口

老年、儿童 / 青少年、妊娠、共病和睡眠呼吸障碍人群的直接证据弱于一般成人原发性失眠。

中成药需要逐产品的高质量、长期、标准化对照研究；不能用“中药整体”替代单品证据。

CBT-I：一致性最高

跨国家、不同方法学体系的推荐方向最稳定；差距更多发生在实施路径，而不是疗效方向。

DORA：更新滞后造成表面差异

AASM 2017 时部分新药证据尚未成熟；欧洲 2023 和 VA/DoD 2025 纳入较新的药物与长期证据，不能把时间差当作药理学冲突。

BZRA / Z 药：短期疗效与长期价值分离

短期入睡或维持改善较明确，但依赖、戒断、跌倒、认知和复杂睡眠行为会拉低长期净获益。

建议的决策顺序

  1. 先完成长期安全与风险管理底座。
  2. 再补老年、肝肾和多药联用的剂量 / 安全边界。
  3. 最后用共病人群和真实世界比较证据支撑差异化与指南沟通。
